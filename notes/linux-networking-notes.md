# Linux and Networking Notes

## IP Address
An IP address identifies a device on a network.

## DNS
DNS (Domain Name System) converts domain names such as google.com into IP addresses.

## HTTP and HTTPS
HTTP is used for communication between web clients and servers.
HTTPS provides encrypted communication using TLS.

## SSH
SSH provides secure remote access to systems and is also used for GitHub authentication.
